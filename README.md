# でんきの道 / 全国の送電線と電気の流れ

日本の基幹送電系統（沖縄を除く全国10エリア）の送電線・変電所・発電所の「つながり」と、電気の流れ（潮流）を地図に表示する Web アプリです。

公開サイト：https://yamanami-works.github.io/grid-flow-map/

> **参考表示です。** 系統の運用や電力の取引などの判断には使わないでください。送電線の位置・接続・潮流の向きには誤りや推測が含まれることがあります。

## 表示の考え方

- 電気的な接続の正しさと、送電線の抜けがないことを、位置の精度より優先しています。
- 一次資料（一般送配電事業者・電力広域的運営推進機関（OCCTO）・発電事業者などの公表資料）を正とし、OpenStreetMap などは補助として使っています。
- 資料で確かめられない接続は、確定させずに「推測」と表示します。線ごとの根拠の確かさ（照合区分）と出典は、地図で線や設備を選ぶと詳細欄に出ます。
- 公表のない値はゼロや仮の値で埋めず、「未確認」（灰色）として区別します。
- 潮流は OCCTO の公表値（30分値）を GitHub Actions で定期的に取得し、検証してから配置しています。

## 出典

- 潮流・運用容量：電力広域的運営推進機関（OCCTO）系統情報サービス（加工して表示）
- 送電線・設備の地理データ：© OpenStreetMap contributors（ODbL 1.0。加工したデータも ODbL 1.0 で提供します）
- 背景地図：国土地理院（地理院タイル）。送電線の経路の一部に国土地理院 ベクトルタイル（試験公開）を加工して使用
- 各社の公表資料（送電線・設備の名称・接続・状態の確認）

## 使い方（開発）

Node.js 22 以上。

```sh
npm ci
npm run dev        # http://127.0.0.1:5173/
npm test
npm run build      # dist/ に出力
npm run check:publish
```

このリポジトリには潮流のデータを含めません。手元で表示・ビルドするには、先に `node scripts/update-all.mjs` で取得してください。データの原本（各社・OCCTO の資料）とデータ準備の道具・調査記録・運用の文書は含めていないため、地図のデータ（`public/data/`）を一から作り直すことはできません。それらを使うテストは、GitHub Actions では飛ばします（`tests/raw-data.mjs`）。iOS 版は当面公開しません（`capacitor.config.ts` と `ios:*` のスクリプトは残していますが、`ios/` は含めていません）。
